## ۴.۲ ترتیب دقیق کارها در هر مرحله

### مرحله ۲ — گام‌های فنی (به ترتیب اجرا)
1. `ProductRepository` کامل: CRUD + بارکد یکتا + تاریخچه قیمت (✅ انجام شد)
2. `SaleRepository` + `PosViewModel`: سبد، تخفیف، پرداخت ترکیبی، ثبت اتمیک (✅ انجام شد)
3. `InventoryRepository`: ورود/خروج/اصلاح/انبارگردانی + گزارش گردش (✅ انجام شد)
4. اسکن بارکد با CameraX + ML Kit (⏳)
5. چاپ فاکتور (ESC/POS بلوتوث) و اشتراک PDF (⏳)
